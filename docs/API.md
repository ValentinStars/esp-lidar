# Спецификация API и Сетевых протоколов

В данном документе описано взаимодействие микроконтроллера ESP32 и Python-сервера.

## 1. UDP Auto-Discovery

При включении устройство регулярно отправляет UDP Broadcast пакеты (каждые 15 секунд), чтобы найти сервер в локальной сети.

**Порт рассылки:** `44444`

**Формат пакета (JSON):**
```json
{
  "sn": "ESP-A1B2C3D4E5F6",
  "ip": "192.168.1.150",
  "mac": "A1:B2:C3:D4:E5:F6",
  "fw_ver": "1.0.0",
  "mode": "unconfigured",
  "type": "discovery"
}
```

Сервер слушает порт `44444`, получает пакет и регистрирует устройство в БД.

## 2. MQTT Протокол

После обнаружения сервера, устройство подключается к MQTT брокеру (на IP-адресе сервера, порт `1883`).

### Публикация от Устройства к Серверу

*   **Топик:** `lidar/<sn>/telemetry`
    *   **Описание:** Отправляется каждые 15 секунд. Содержит телеметрию.
    *   **Payload:** `{"sn": "ESP-A1B2C3D4E5F6", "ip": "192.168.1.150", "status": "monitoring", "mode": 1, "uptime": 120, "free_heap": 250000, "alerts_count": 0, "lidar": {"valid_pkts": 1500, "crc_err": 0}}`

*   **Топик:** `lidar/<sn>/alerts`
    *   **Описание:** Отправляется при возникновении инцидента.
    *   **Payload:** `{"sn": "ESP-A1B2C3D4E5F6", "pane_id": 1, "zone_id": 1, "alert_type": "destruction", "distance_mm": 500, "calib_dist_mm": 1200, "delta_mm": 700}`
    *   *alert_type может быть: destruction (разрушение), proximity (приближение), restored (восстановлено).*


*   **Топик:** `lidar/<sn>/raw_scan`
    *   **Описание:** сырой скан 360 точек (режим калибровки).
    *   **Payload:** `{"sn": "ESP-A1B2C3D4E5F6", "scan": [1200, 1201, 1199, ...]}`

### Публикация от Сервера к Устройству

*   **Топик:** `lidar/<sn>/cmd`
    *   **Описание:** Команды управления устройством.
    *   **Payload:** `{"cmd": "reboot"}` или `{"cmd": "start_monitoring"}` или `{"cmd": "start_calib"}`

*   **Топик:** `lidar/<sn>/calib_data`
    *   **Описание:** Конфигурация зон (от сервера к устройству).
    *   **Payload:** `{"panes": [{"id": 1, "zones": [{"start_a": 0, "end_a": 90, "baseline": 1000, "tolerance": 100}]}]}`

## 3. HTTP API Сервера

Сервер предоставляет HTTP API для дашборда (порт `8080`).

*   `GET /api/stats` — Общая статистика сети.
*   `GET /api/devices` — Список всех устройств.
*   `GET /api/devices/<sn>` — Данные конкретного устройства.
*   `GET /api/devices/<sn>/scan` — Последний сырой скан 360 точек (только в режиме калибровки).
*   `POST /api/devices/<sn>/cmd` — Отправка команды на устройство.
*   `GET /api/alerts` — Получение последних алертов (поддерживает параметр `?limit=N`).

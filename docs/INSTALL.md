# Установка Сервера

Серверная часть отвечает за управление устройствами ESP32, сбор телеметрии, обработку инцидентов и предоставление веб-интерфейса.

## 1. Требования

Для запуска сервера вам понадобятся:
- Linux / macOS / Windows (с WSL).
- Установленный Python 3.9 или выше.
- Установленный Docker и Docker Compose (для базы данных MariaDB).
- Локальная сеть, в которой сервер и микроконтроллеры могут "видеть" друг друга.

## 2. Запуск Базы Данных

Мы используем MariaDB в качестве основной СУБД. Конфигурация уже прописана в файле `docker-compose.yml`.

1. Откройте терминал в корневой папке проекта.
2. Выполните команду для запуска контейнера в фоновом режиме:
   ```bash
   docker-compose up -d
   ```
3. Убедитесь, что контейнер запущен:
   ```bash
   docker ps
   ```

*Примечание: Сервер настроен на автоматическое создание нужных таблиц при первом запуске, если они отсутствуют в базе данных.*

## 3. Запуск Python Сервера

1. Перейдите в папку сервера:
   ```bash
   cd server
   ```
2. Установите зависимости Python:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите сервер:
   ```bash
   python3 app.py
   ```
4. В терминале должно появиться сообщение `[SERVER] Веб-сервер запускается на http://0.0.0.0:8080`.

## 4. Доступ к веб-дашборду

Откройте браузер и перейдите по адресу: [http://localhost:8080](http://localhost:8080) (или используйте IP-адрес сервера в вашей локальной сети, например `http://192.168.1.100:8080`).

Теперь сервер готов принимать сигналы Auto-Discovery от модулей ESP32!

# Инструкция по прошивке (FIRMWARE)

Данное руководство поможет вам быстро прошить плату **ESP32-S3-DevKitC-1** для работы в составе LiDAR IoT Network.

## Способ 1: Использование готового бинарника (Для чайников)

Самый быстрый способ — использовать заранее скомпилированный бинарный файл прошивки из папки `bin/`. 
Для этого вам понадобится утилита `esptool` (или веб-прошивальщик Espressif).

1. Подключите ESP32-S3 к компьютеру через USB-кабель (в порт "UART" или "USB").
2. Убедитесь, что у вас установлен Python, затем установите esptool:
   ```bash
   pip install esptool
   ```
3. Выполните прошивку (замените `/dev/ttyUSB0` на ваш COM-порт, например `COM3` на Windows):
   ```bash
   esptool.py -p /dev/ttyUSB0 -b 460800 --before default_reset --after hard_reset --chip esp32s3 write_flash --flash_mode dio --flash_size detect --flash_freq 80m 0x0 bin/firmware.bin
   ```
   *Примечание: в папке bin лежит объединенный бинарник (bootloader + partitions + firmware).*

## Способ 2: Сборка из исходников через PlatformIO (Для разработчиков)

Если вы хотите внести изменения в код, вам необходимо скомпилировать прошивку самостоятельно.

1. Установите **Visual Studio Code** и расширение **PlatformIO IDE**.
2. Откройте папку `firmware` в VS Code.
3. Дождитесь, пока PlatformIO установит все необходимые toolchains (зависимости).
4. Подключите ESP32-S3.
5. Нажмите иконку **Upload (Стрелочка вправо)** в нижней панели PlatformIO. 
   - Процесс сборки и загрузки прошивки пройдет автоматически.

## Аппаратное подключение

1. **W5500 Ethernet:** Подключается по шине SPI к пинам ESP32-S3. (По умолчанию настроены стандартные SPI пины S3).
2. **Lidar LDROBOT D500:** 
   - Питание: 5V
   - Земля: GND
   - TX Лидара -> RX Пину ESP32 (UART2)
   - Baudrate: 230400 bps

После успешной прошивки устройство автоматически получит IP-адрес по DHCP и начнет отправку UDP Broadcast пакетов для поиска сервера.

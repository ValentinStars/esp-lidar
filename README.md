# LiDAR IoT Network (Glass Integrity Monitoring)

Интеллектуальная система постоянного мониторинга целостности стёкол (например, на остановочных павильонах) на базе микроконтроллера **ESP32-S3**, сетевого модуля **W5500 (Ethernet)** и высокоточного лазерного дальномера **LDROBOT D500**.

Система автоматически обнаруживает разбитие стекол (вандализм), а также сигнализирует о длительном перекрытии зон (загрязнение, заклеивание плакатами).

## 🗂 Структура репозитория

* `/firmware` — исходный код прошивки для ESP32-S3 (на базе PlatformIO / Arduino).
* `/server` — Python-сервер (Flask) с веб-дашбордом и MQTT-брокером.
* `/docs` — подробные инструкции и документация.
* `/bin` — готовые скомпилированные бинарники для быстрой прошивки.
* `docker-compose.yml` — конфигурация для быстрого запуска базы данных (MariaDB/MySQL).

## 🚀 Быстрый старт

1. **Серверная часть:** Поднимите базу данных с помощью Docker и запустите Python-сервер. Подробности см. в [Установка сервера (INSTALL.md)](docs/INSTALL.md).
2. **Прошивка устройства:** Прошейте ваш ESP32-S3 готовым бинарником из папки `/bin`. Подробности см. в [Инструкции по прошивке (FIRMWARE.md)](docs/FIRMWARE.md).
3. **Настройка:** Зайдите на веб-дашборд сервера, выберите устройство и проведите калибровку зон остекления.

## 🛠 Основные компоненты и фичи

* **Auto-Discovery:** Устройства автоматически находят сервер в локальной Ethernet сети (UDP Broadcast на порт 44444).
* **A/B OTA Обновления:** Беспроводное обновление прошивки через HTTP с автоматическим откатом (Rollback) на предыдущую стабильную версию в случае ошибки или зависания.
* **Watchdog и Отказоустойчивость:** Аппаратный WDT на 5 секунд защищает систему от зависаний.
* **Буферизация (LittleFS):** Если сервер недоступен, алерты сохраняются во flash-память контроллера (до 500 штук) и отправляются пачкой при восстановлении связи.
* **Боевой алгоритм мониторинга:** 
  * Мгновенный детект разбития (увеличение дистанции).
  * Таймер задержки на перекрытие (игнорирует кратковременные препятствия, например, прохожих).

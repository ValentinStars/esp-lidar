# Инструкция по развертыванию LiDAR IoT Network

Данный архив содержит полностью готовый к бою проект.

## 1. Запуск сервера (Linux / Raspberry Pi / VPS)
Все зависимости (MariaDB) и настройки запускаются автоматически через скрипт-установщик.

1. Убедитесь, что у вас установлен Docker (для БД MariaDB).
2. Выполните установку:
```bash
cd scripts
sudo chmod +x install_server.sh
sudo ./install_server.sh
```
3. Скрипт развернёт Flask, настроит `mosquitto` (MQTT-брокер) и создаст Systemd-сервисы.
4. Веб-дашборд будет доступен по адресу: `http://<ВАШ_IP>:8080/`

## 2. Прошивка ESP32-S3
Файл прошивки `firmware/firmware.bin` уже скомпилирован и содержит все последние патчи.

1. Подключите ESP32-S3 по USB.
2. Используйте утилиту `esptool.py` (или веб-прошивальщик ESP Web Tools) для заливки:
```bash
esptool.py --chip esp32s3 write_flash -z 0x10000 firmware/firmware.bin
```

## 3. Настройка системы
1. Запустите ESP32. Она автоматически получит IP-адрес по DHCP и найдёт сервер.
2. Откройте веб-дашборд сервера, найдите устройство и перейдите в раздел "Диагностика".
3. Нажмите "Перевести в режим калибровки" (Start Calibration).
4. Укажите зоны на карте.
5. Нажмите "Сохранить конфигурацию". Прошивка применит параметры (в том числе таймаут задержки препятствий) и автоматически перейдет в рабочий режим мониторинга.
